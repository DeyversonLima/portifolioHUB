# Contribuindo

1. Crie uma branch a partir de `main`.
2. Não adicione certificados brutos, tokens ou arquivos pessoais.
3. Atualize os catálogos em `data/`, sem duplicar cards no HTML.
4. Execute `npm run check` e `npm audit`.
5. Descreva contexto, alterações e evidências no pull request.

Commits devem ser pequenos e descritivos, preferencialmente seguindo Conventional Commits.
