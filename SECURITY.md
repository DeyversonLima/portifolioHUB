# Política de Segurança

## Versões suportadas

Somente a versão mais recente publicada no GitHub Pages recebe correções.

## Relatar uma vulnerabilidade

Use o recurso **Security → Report a vulnerability** do repositório. Não publique tokens, documentos pessoais, credenciais ou passos de exploração em issues públicas.

Inclua, quando possível:

- componente afetado;
- impacto observado;
- passos seguros para reprodução;
- sugestão de correção.

## Escopo

As demonstrações de login e estoque são simulações locais. Os projetos de cibersegurança são educacionais e devem ser executados somente em laboratórios isolados e sistemas explicitamente autorizados.

Certificados completos não são armazenados neste repositório.
